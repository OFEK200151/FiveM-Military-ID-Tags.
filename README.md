# 🏷️ JS-IDTAG
### Military ID Tags for FiveM

**Name · Unit · Voice indicator · Team-only visibility**

📥 [**Free download on Discord**](https://discord.gg/XEpk5MUJEh)

**🆓 100% FREE**

</div>

---

Clean ID tags above players — like a uniform shoulder patch. Look at a soldier and see his name and his unit.
The name turns **yellow while he talks** and **red while silent** — no more *"who said that?"* on the radio.

## ✨ Features
- 🏷️ **Two lines above every player**
  - voice icon + **name** — 🟡 talking · 🔴 silent
  - **unit** — e.g. *Golani* (per job, optional grade: *Golani | Sergeant*)
- 🆔 **Server ID** shown small next to the name
- 👥 **Team-only visibility** — you see only your own team's tags, and only your team sees yours
  - decided by the server: the other team's names never even reach your game
  - change job and it switches at once
- 👁️ **Fades with distance** · **no tags through walls**
- 🎭 **Loaded characters only** — no tags in character selection
- ✏️ **Custom tag name** per character — saved in QBCore metadata, no extra SQL
- 🙈 Hide **your** tag, or hide **all** tags on your screen
- 🛡️ **Server-authoritative** — the client only draws, can't fake a tag
- ⚡ **Lightweight** — a scan every 400 ms, drawing only when players are near

## ⚙️ Configurable
| Option | What |
|---|---|
| `Config.Teams` | which jobs are one team |
| `Config.JobSubtitles` | unit per job |
| `Config.ShowGrade` | add the grade to the unit |
| `Config.AllowedJobs` / `RequireOnDuty` | who gets a tag |
| `Config.Distance` / `FadeFrom` / `LineOfSight` | visibility |
| `Config.Colors` / `Font` / sizes | the look |
| `Config.Text` | all messages |

## 💬 Commands
| Command | What it does |
|---|---|
| `/idtag` | Show / hide **your** tag |
| `/idtags` | Show / hide **all** tags on your screen |
| `/tagname <name>` | Set your tag name |
| `/tagreset <id>` | Reset a player's tag name *(admin)* |

## 📦 Requirements
- QBCore
- pma-voice
- English + Hebrew versions included
